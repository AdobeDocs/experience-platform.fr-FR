# Libellés d’utilisation des données dans l’API Dataset Service

En dehors de l’API Catalog Service, l’API [!DNL Dataset Service] fournit des points d’entrée pour gérer les libellés d’utilisation des données pour les jeux de données. Pour savoir comment effectuer des appels vers ces points d’entrée, reportez-vous au guide sur la [gestion des libellés d’utilisation des données à l’aide de l’API](../../data-governance/labels/dataset-api.md) dans la documentation sur la gouvernance des données de Adobe Experience Platform.
