# Créer une connexion en continu authentifiée

La collecte de données authentifiées permet aux services Adobe Experience Platform, tels que [!DNL Real-Time Customer Profile] et [!DNL Identity], de distinguer les enregistrements provenant de sources approuvées de ceux provenant de sources non approuvées. Les clients qui souhaitent envoyer des informations d’identification personnelle (PII) peuvent le faire en envoyant des jetons d’accès dans le cadre de la demande POST.

Pour savoir comment créer une connexion en continu authentifiée, veuillez lire le guide de l’API source [HTTP](../../sources/tutorials/api/create/streaming/http.md).
