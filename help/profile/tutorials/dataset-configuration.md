# Configurer un jeu de données pour Profil à l’aide d’API

Le tutoriel relatif à l’activation d’un jeu de données à utiliser dans le profil client en temps réel et le service d’identités Adobe Experience Platform comprend les étapes de création d’un jeu de données et de configuration d’un jeu de données existant. Le tutoriel décrit également les étapes à suivre pour ingérer des données dans le jeu de données et confirmer l’ingestion réussie des données dans Profile et Identity Service.

Pour accéder à ce tutoriel, consultez le tutoriel [Activer un jeu de données pour le profil et l’identité à l’aide d’API](../../catalog/datasets/enable-for-profile.md), qui fait partie de la documentation sur les jeux de données.
