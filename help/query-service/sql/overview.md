# Référence SQL de Query Service

[!DNL Query Service] permet d’utiliser le langage SQL ANSI standard pour les instructions `SELECT` et d’autres commandes limitées. [!DNL Query Service] n’inclut pas la fonctionnalité Langage de définition de données ni Langage de manipulation de données . Les données interrogées via le service proviennent de [!DNL Experience Data Lake], qui contient des jeux de données en grande partie immuables.
