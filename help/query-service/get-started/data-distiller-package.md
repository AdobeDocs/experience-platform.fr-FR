# Package Distiller de données

Data Distiller est une offre groupée qui comprend un sous-ensemble des fonctionnalités de Adobe Experience Platform. Ce package est destiné à la préparation des données post-ingestion pour le profil client en temps réel ou les cas d’utilisation des données analytiques par les requêtes par lots exécutées dans Query Service.

Consultez les guides sur la manière de [visualiser vos informations SQL](../../dashboards/sql-insights-query-pro-mode/overview.md) ou d’utiliser le mode pro de requête pour [mener des analyses complexes avec des requêtes SQL personnalisées et transformer vos données en graphiques faciles à interpréter](../../dashboards/sql-insights-query-pro-mode/overview.md). Vous pouvez utiliser le mode Query Pro pour créer des informations et des visualisations personnalisées sur vos tableaux de bord personnalisés.
