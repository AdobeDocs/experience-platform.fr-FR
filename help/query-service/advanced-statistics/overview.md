# Présentation de la modélisation statistique avancée avec Trusted Flow

>[!AVAILABILITY]
>
>Cette fonctionnalité est disponible pour les clients qui ont acheté le module complémentaire Distiller de données. Pour plus d’informations, contactez votre représentant ou représentante Adobe.

La modélisation statistique est utilisée pour faire des prédictions, détecter des modèles et générer des informations à partir des données. Cela s’applique à des jeux de données de grande taille et de dimensions élevées, avec des structures complexes et distribuées. Utilisez l’extension Data Distiller SQL pour tirer parti des modèles statistiques et transformer les données brutes en simplifiant et en automatisant le prétraitement des données sur les jeux de données volumineux en temps opportun, en parallèle et de manière évolutive.

Cette série de documents fournit un guide complet sur l’utilisation de l’extension Data Distiller SQL pour effectuer des opérations traditionnelles d’ingénierie des fonctionnalités et de machine learning sur Trusted Flow. Ces documents sont conçus pour vous aider à implémenter et à exploiter efficacement l’ingénierie de fonctionnalités SQL, la création de modèles SQL et le traitement algorithmique. La documentation vous guide à travers les aspects critiques nécessaires pour intégrer de manière transparente la modélisation statistique avancée dans vos workflows de données SQL standard.

## Fonctionnalités {#capabilities}

Data Distiller vous fournit les outils nécessaires pour transformer les données brutes en fonctionnalités significatives, créer et entraîner des modèles statistiques et utiliser ces modèles pour une analyse prédictive. La documentation de est organisée pour vous aider à comprendre et à appliquer ces fonctionnalités étape par étape :

1. **Ingénierie des fonctionnalités** : découvrez comment prétraiter vos données en extrayant, transformant et sélectionnant les fonctionnalités les plus pertinentes. Découvrez les fonctions SQL disponibles qui simplifient et automatisent le processus d’ingénierie des fonctionnalités et comment vous assurer que vos données sont préparées de manière optimale pour la formation des modèles.

2. **Modèles** : découvrez comment gérer, évaluer et prédire les modèles statistiques avancés à l’aide de SQL. Comprenez les processus principaux impliqués dans SQL pour définir le cycle de vie de ces modèles sur vos jeux de données.

3. **Algorithmes** : explorez les algorithmes de modélisation statistique avancés pris en charge par Data Distiller, notamment la mise en grappe, la classification et la régression. Ce document décrit le processus d’utilisation des algorithmes disponibles, leurs paramètres et la génération de modèles spécifiques aux clients à l’aide de l’extension SQL pour répondre aux besoins de votre entreprise.
