# Mode de requête pro

Utilisez le mode requêteur pour effectuer des analyses complexes avec des requêtes SQL personnalisées et transformer vos données en graphiques faciles à interpréter. Cette fonctionnalité permet un plus grand degré de personnalisation de vos informations et filtres qui peut s’adapter à des cas d’utilisation spécifiques. Vous pouvez [créer des informations et des visualisations personnalisées sur vos tableaux de bord](../../../dashboards/sql-insights-query-pro-mode/overview.md) et répondre aux besoins des audiences techniques et non techniques en téléchargeant vos informations sous forme de fichiers CSV.

Consultez la documentation du mode query pro pour savoir comment [utiliser des requêtes SQL pour générer des informations](../../../dashboards/sql-insights-query-pro-mode/overview.md) pour vos tableaux de bord personnalisés, ou [télécharger vos informations sous la forme d’un fichier CSV](../../../dashboards/sql-insights-query-pro-mode/view-more.md#download-csv).
