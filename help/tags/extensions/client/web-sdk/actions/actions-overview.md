# Types d’actions

Cette page répertorie toutes les actions prises en charge dans une règle de balise. Pour créer ou modifier les actions dans une règle de balise :

1. Connectez-vous à [CX Enterprise](https://experience.adobe.com?lang=fr) à l’aide de vos informations d’identification Adobe ID.
1. Accédez à **[!UICONTROL Collecte de données]** > **[!UICONTROL Balises]**.
1. Sélectionnez la propriété de balise de votre choix.
1. Accédez à **[!UICONTROL Règles]**, puis sélectionnez la règle de votre choix.
1. Sous [!UICONTROL Actions], sélectionnez une action existante ou créez-en une.
1. Définissez le champ déroulant [!UICONTROL Extension] sur **[!UICONTROL Adobe Experience Platform Web SDK]**, puis sélectionnez le [!UICONTROL Type d’action] souhaité.

L’extension de balise Web SDK propose les actions suivantes :

* [**[!UICONTROL Propositions d’application]**](apply-propositions.md) : effectuez des propositions de rendu dans les applications monopages sans incrémenter de mesures.
* [**[!UICONTROL Appliquer la réponse]**](apply-response.md) : effectuez une action en fonction d’une réponse de l’Edge Network.
* [**[!UICONTROL Évaluer des ensembles de règles]**](evaluate-rulesets.md) : déclenchez manuellement une évaluation d’ensemble de règles.
* [**[!UICONTROL Get Media Analytics tracker]**](get-media-analytics-tracker.md) : exportez l’API Media héritée vers un objet de fenêtre.
* [**[!UICONTROL Rediriger avec une identité]**](redirect-with-identity.md) : permet le partage d’un identifiant visiteur sur plusieurs domaines que vous possédez.
* [**[!UICONTROL Envoyer l’événement]**](send-event.md) : envoie les données d’événement à Edge Network.
* [**[!UICONTROL Envoyer l’événement multimédia]**](send-media-event.md) : envoie les données multimédia à Edge Network.
* [**[!UICONTROL Définir le consentement]**](set-consent.md) : permet de définir le consentement souhaité pour le visiteur.
* [**[!UICONTROL Mettre à jour la variable]**](update-variable.md) : permet de modifier un élément de données [variable](../data-element-types.md#variable).
