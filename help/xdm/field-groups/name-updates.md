# Mises à jour du nom du groupe de champs de schéma

Les noms de plusieurs groupes de champs de schéma du modèle de données d’expérience (XDM) ont été modifiés. Puisque la structure des champs de ces groupes de champs reste la même, les modifications de nom seules ne doivent pas affecter les schémas existants qui utilisent ces groupes de champs. Toutefois, pour rechercher et utiliser ces groupes de champs dans l’interface utilisateur de Adobe Experience Platform, leurs nouveaux noms doivent être utilisés.
